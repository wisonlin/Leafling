Create your first app.
Then make it yours.

Connect AI, describe one useful tool, open the saved result, and keep improving it in chat.

Steps refer to Leafling 1.5.5. New to Leafling? Try the official Photo Wall example first, without connecting AI.

Leafling is for personal apps: the photo view, checklist, or small utility you want to shape around your own routine. Describe what you want in chat, open the result inside Leafling, then return to chat to change it. You do not need to write the code yourself.

From a request to a tool you can use

  1. Connect the AI you want to use.

    Open Settings → AI Connection. Choose ChatGPT and tap Connect ChatGPT to connect your existing account. Or choose OpenAI API key, enter your own key and a Model ID available to your API account, then tap Save API settings. You only need one connection.

    AI requests need internet. Your chosen account’s access, usage limits, and billing apply. Leafling Pro provides more saved-app space; it does not provide model usage or API credits. See OpenAI’s ChatGPT connection guidance and API pricing for current account terms.

  2. Ask for one specific app.

    Start a new chat in Chats. Say that you want an app, what you will use it for, and what its buttons should do. For a photo tool, you could paste the request below.

  3. Open the saved result and check it.

    Wait for the run to finish and look for the app card marked Saved to your Apps. Tap the card or Open App to open its own preview screen. A text reply alone is not a saved app.

    If the run reports an error or no saved card appears, check the message and your connection before trying again. Do not treat a progress step as a finished result.

  4. Use it, then reopen it from Apps.

    For the photo request, tap Load Photos in the generated app and review any iOS permission request. Allow only the access you want. Check that photos load, or that the app explains why they cannot. Star a photo, return to Apps, reopen your saved app, and check whether the pick remains.

    These are checks to perform on your result, not a guarantee that AI will implement every detail correctly. Generated apps run inside Leafling; they are not separate App Store downloads.

The free plan holds up to 3 apps you create or import. Editing the same app uses the same saved-app slot. You can try the official example below before sending any AI request. Need setup help? Visit Support.

The connection to your phone

The apps you create use web interfaces inside Leafling. Supported actions connect through Leafling’s JSON Bridge to native iOS SDKs. That connection lets a personal interface work with phone data and system actions, subject to the device and the access you allow.

For example, a photo app can read the Photos library within your permitted scope. A checklist can ask to add an item to Reminders after your confirmation. The interface is yours to shape; iOS still controls sensitive access.

Try Photo Wall in three steps

No ChatGPT connection is needed to preview or save this official example.

  1. Open the official example.

    Open Discover, find Photo Wall, and tap Preview. On the welcome screen, Try Examples Free takes you to Discover.

  2. Choose what it can read.

    If iOS asks, choose your Photos access. The example loads recent items automatically; tap Load Recent Week to retry. It looks at the past seven days. If it cannot read recent photos, it may show sample content—check the message above the grid.

  3. Save your copy and open it.

    Tap Use This, then go back and open Apps → Photo Wall. Saving opens a linked chat with a prefilled message; you do not need to send it.

The free plan holds up to 3 apps you create or import. Trying examples uses no slot; saving with Use This does.

Want to make your own version? Follow the creation and editing steps above. The example’s prefilled chat stays unsent until you choose to send it.

A personal workflow to explore

A voice checklist illustrates the kind of connection we want to make easy: speak, review the transcript, choose tasks, and confirm which ones to add to Reminders. Later, return to chat to separate work and personal categories inside your own app.

Keep changing the same app

A personal tool does not have to be finished in one request. You can ask for a different layout, another category, or an extra supported action, then keep using the app inside Leafling. The point is a tool that fits you and can change with you.

Leafling is free to download. You can try official examples before signing in. AI chat, creation, editing, and AI features in personal apps require internet and your chosen ChatGPT or OpenAI API connection; its access, usage limits, and billing apply. Generated apps run inside Leafling.
