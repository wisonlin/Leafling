Your first app in Leafling.

Try a ready-made tool, save it to Apps, or create your own tool in chat.

These steps show Leafling 1.5.6.

Try Photo Wall first Create an app in chat Watch the earlier example

Try Photo Wall without connecting AI.

  1. Open Discover → Photo Wall → Preview. Choose Try Examples Free on the welcome screen if you're new to Leafling. Preview starts with sample pictures and does not use a saved-app slot.
  2. Choose whether to load your Photos. Tap Load My Recent Photos to request access. Allow only what you want to share with the tool. If you decline or no permitted recent items are available, you can keep using the samples.
  3. Check the status above the photos. It tells you whether you're seeing samples or recent items from the Photos access you allowed. The gallery can only show photos that iOS gives Leafling access to.
  4. Save and reopen. Tap Use This to keep a copy. If a linked chat opens, you can leave it without sending anything. Find Photo Wall in Apps and tap it to open the same tool.

Need to change what Leafling can see? Use the Photos permission in iOS Settings. See Photos permission details for how consent works when a task uses AI.

Create a tool in chat.

  1. Set up an AI connection in Settings. AI chat, creation and editing use internet and the AI connection you set up. See connection instructions and usage terms.
  2. Ask for a specific app. Describe what it should show and what you want to do with it.
“Create a packing checklist app with five items and show me how many I’ve packed.”
  1. Open the result card in chat. When an app is saved, tap Open App to check that it does what you asked for.
  2. Open it again from Apps. Find the same icon in the Apps grid. If you want a change, return to that tool’s chat and ask for it there.

The screens use a working local sample and an example chat. You can check the controls and reopen behavior in your own tool after it is saved.
