# What's New

## Version 1.4

Leafling has a cleaner workspace for building and using your tiny apps.

- Use bottom tabs for Apps, Build, Discover, and Settings.
- Open runnable apps quickly from Apps.
- Keep AI build chats organized in Build.
- Try official examples and native capability demos in Discover.
- Support Leafling with an optional Tip Jar that does not unlock or limit features.

## Version 1.3

This update improves project organization, editing controls, and preview reliability while building and revisiting your apps.

- Open ready projects quickly from the home screen.
- Edit project names, icons, descriptions, and author details from App Info.
- Connect an existing ChatGPT account from Settings instead of pasting API keys.
- Use improved preview behavior for local projects and examples.

## Version 1.0

Leafling helps you learn how web apps are created with AI.

- Describe an idea and generate a working web app.
- Preview generated projects instantly inside Leafling.
- Continue refining projects through chat.
- Try built-in native capability examples.
- Connect an existing ChatGPT account to generate and revise projects.

Leafling is focused on learning, experimentation, and lightweight local prototyping.
